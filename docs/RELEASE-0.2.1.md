# StorageWarden 0.2.1 - early preview

Find what takes up space on your Mac, review what to keep, and see which processes are busy. Free and open source, with no accounts, ads or tracking.

## Download

Choose **StorageWarden-0.2.1-macOS.dmg** below. Requires macOS 15 or newer; includes Apple silicon and Intel builds. No Xcode installation needed.

1. Double-click the downloaded DMG.
2. Drag StorageWarden onto Applications.
3. Open the app from Applications and choose a folder for your first scan.

The disk image includes a START HERE guide, the privacy policy and the MIT license. The separate SHA-256 file lets technical users compare the download's checksum; it is not a security certification.

## Please read before opening

**This is an ad-hoc-signed preview, not Developer ID signed or notarized by Apple.** macOS may block it. If you are unsure, wait for a notarized release. Do not disable Gatekeeper or bypass malware warnings. See the [installation guide](https://github.com/Sjayeshkumar/StorageWarden/blob/main/docs/INSTALL.txt) and [Apple's explanation](https://support.apple.com/102445).

This package has not been through clean-Mac installation testing or a new runtime test pass. It is intended for people comfortable trying early software, not a claim that every feature is finished or bug-free.

## What is included

- A native app icon and drag-to-Applications disk image.
- Storage maps, file lists, local saved scans and updates while the app runs.
- Cleanup review before moving eligible files to Trash. No automatic deletion.
- Menu-bar CPU, memory and disk-write readings, plus supported system activity readings.
- Simpler first-launch, installation and privacy guidance.

## Privacy first

StorageWarden does not upload your files, scan results or activity readings. Saved scans stay on your Mac; activity readings are not saved as history. Website links, backups and cloud services operate separately under your own settings. [Read the privacy policy](https://github.com/Sjayeshkumar/StorageWarden/blob/main/PRIVACY.md).

## Known limits

Very large scans can still use substantial memory. Changes made while the app is quit need a manual rescan. Possible duplicates are not content-verified. Full app uninstall and per-app GPU readings are not available. Report issues without sharing private file paths or screenshots.
